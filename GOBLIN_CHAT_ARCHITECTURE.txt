API ENDPOINTS:
══════════════

POST /chat/conversations
  ├─ Header: x-api-key (REQUIRED but missing in frontend) ❌
  ├─ Body:
  │  ├─ user_id: string (optional, but should be authenticated)
  │  └─ title: string (optional)
  └─ Response:
     ├─ conversation_id: string
     ├─ title: string
     └─ created_at: ISO string

POST /chat/conversations/{conversation_id}/messages
  ├─ Header: x-api-key (REQUIRED but missing in frontend) ❌
  ├─ Body:
  │  ├─ message: string
  │  ├─ provider: string | null
  │  ├─ model: string | null
  │  └─ stream: boolean (false)
  └─ Response:
     ├─ message_id: string
     ├─ response: string ✓ (correctly used in frontend)
     ├─ provider: string
     ├─ model: string
     └─ timestamp: ISO string

GET /chat/conversations
  ├─ Query: user_id, limit
  └─ Returns: List[ConversationInfo]

GET /chat/conversations/{conversation_id}
  └─ Returns: Conversation with full message history
